# database-llm-roa

Artifacts and supplementary materials for the VLDB 2027 submission.

*This repository is under active documentation construction. Check back soon for an update.*

- `dataset` contains the raw dataset and the various splits used for training.
- `roa-tests` contains chat logs with pre-trained and fine-tuned models, demonstrating Right of Access breakage.
- `scripts` contains all the scripts used for training and inference of models.
