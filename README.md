# database-llm-roa

Artifacts and supplementary materials for the VLDB 2027 submission.

*This repository is under active documentation construction. Check back soon for an update.*

- `roa-tests` contains chat logs with pre-trained and fine-tuned models, demonstrating Right of Access breakage. Navigate [here](roa-tests/README.md) to read more about our experiments.

- `dataset` contains the raw dataset and the various splits used for training. For more information about the dataset, navigate [here](dataset/README.md).
 
- `scripts` contains all the scripts used for training and inference of models. A high level workflow, detailing how the scripts interact with one another is available [here](scripts/README.md).
